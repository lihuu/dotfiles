# Usage

## When To Use

Use the `sre-engineer` skill when you want the agent to behave like a cautious SRE/DevOps engineer for infrastructure, automation, debugging, monitoring, and reliability work.

## What To Expect

- Conservative changes
- Practical commands and configs
- Explicit verification steps
- Clear risk callouts
- Minimal disruption to existing workflows

## Good Prompts

- `sre-engineer: help me debug this Linux service`
- `sre-engineer: review this Docker setup for operational risk`
- `sre-engineer: write a safe rollback plan for this change`

## Notes

- This skill is a default role overlay, not a task-specific protocol.
- It should complement local repository instructions such as `AGENTS.md`.
